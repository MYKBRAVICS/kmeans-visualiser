What the starting centroids do

Press Move starting centroids a few times on the overlapping data and run it again. The final grouping changes. k-means converges to a local minimum, not a best answer, which is why real implementations restart from many random seeds and keep the best result.

Reading the silhouette

Silhouette compares how close each point sits to its own cluster against the nearest other one. Rousseeuw's rough guide: above 0.7 is strong, 0.5 to 0.7 reasonable, 0.25 to 0.5 weak, below that no substantial structure.

Treat those as orientation rather than a test. The honest comparison is against what the same algorithm scores on data you know has no structure.

Why the noise setting matters

Load the uniform noise data and run it. There are no groups in it at all, and the algorithm still returns k tidy ones, every time, with boundaries that look deliberate.

It will do exactly the same thing to your data. That is the reason a clustering result needs a stability check and a null comparison before anyone describes the groups as types.
